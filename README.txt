PARKLINE — PRECISION PARKING SIMULATOR

HOW TO PLAY
1. Extract the ZIP file (if downloaded as ZIP).
2. Open index.html in Chrome, Edge, Firefox, or Safari. No installation or internet connection is required.
3. Click START ENGINE.

CONTROLS
- Arrow keys or WASD: drive and steer
- Up / W: accelerate
- Down / S: reverse
- Left / A and Right / D: steer
- Escape: pause
- On touch screens, use the on-screen directional controls.

GAMEPLAY
- Complete all 3 levels: Training Grounds, City Centre, Precision Challenge.
- Avoid cars, cones, barriers, and lot boundaries.
- Park fully inside the glowing bay, aligned with the bay, and remain still briefly.
- Three collisions end the attempt. Restart the level to try again.
- Score includes a time bonus and collision penalty.

TECHNOLOGY
Single-file HTML, CSS, and vanilla JavaScript. No framework, external assets, dependencies, or network requests.
